Current install method

Stars2Cells is currently distributed as source code. There is no executable, dmg, or zip release yet. To use the pipeline, clone the repository and run it in a Python environment.

Note: If you are new to Python environments, the steps below use Conda because it is the most reproducible for scientific stacks.

Quick start (Conda)

Recommended for most users. This creates an isolated environment so Stars2Cells dependencies do not affect other projects.

# 1) Clone the repository git clone https://github.com/ariasarch/Stars2Cells_Alpha_Release.git cd Stars2Cells_Alpha_Release # 2) Create and activate an environment conda create -n s2c python=3.11 -y conda activate s2c # 3) Install dependencies pip install -r requirements.txt # 4) Run the pipeline (example usage will be documented in docs) # Start by viewing available scripts or modules: python -c "import sys; print('Python OK:', sys.version)"
Tip: If your repository uses a package layout later (pyproject.toml or setup.cfg), you can switch to editable installs with: pip install -e .

Quick start (pip + venv)

If you do not use Conda, you can use Python venv. This is fine as long as you have a compatible Python installed.

# 1) Clone the repository git clone https://github.com/ariasarch/Stars2Cells_Alpha_Release.git cd Stars2Cells_Alpha_Release # 2) Create and activate a virtual environment python -m venv .venv # macOS / Linux: source .venv/bin/activate # Windows (PowerShell): # .venv\Scripts\Activate.ps1 # 3) Install dependencies pip install -r requirements.txt # 4) Sanity check python -c "import sys; print('Python OK:', sys.version)"

Recommended environment

Python 3.10 to 3.12 is recommended. Stars2Cells depends on common scientific Python packages. If optional GPU acceleration is added later, this page will include those setup steps.
