Core idea

S2C matches neurons across sessions by leveraging *local geometric structure* (constellations) instead of a single global alignment. Quads are sampled across scales, hashed into invariant signatures, and used to propose correspondences that are verified via local transform hypotheses.

Inputs

ROI spatial footprints or centroids per session (optionally with shape descriptors: area, convexity, spatial entropy).

Outputs

Cross-session match list (ID registry), confidence scores, QC summaries, and optional diagnostic plots.

Pseudo-pipeline

1) Extract ROIs / centroids 2) Draw quads across multiple size scales 3) Hash quads into invariant signatures 4) Retrieve candidate correspondences via hash matches 5) Generate local transform hypotheses 6) Verify via reprojection + descriptor filtering 7) Consensus selection + registry construction 8) QC: match density, residual errors, outlier maps
