Inputs

Required input format

Stars2Cells currently operates on neuron centroid data only, provided as one .npy file per session. Each file must contain a Python dictionary saved with numpy.save(..., allow_pickle=True).

  • File naming: {animal_id}_{session_id}.npy (numeric IDs only)
  • One file per session, all placed in a single input directory
  • Minimum neurons: ≥ 4 per session (sessions below this are skipped)

Required dictionary keys

Each .npy file must load to a dictionary containing the following five keys:

  • centroids_x — x-coordinates of neuron centroids (pixels)
  • centroids_y — y-coordinates of neuron centroids (pixels)
  • roi_ids — unique ROI identifiers within the session
  • subject_id — animal identifier (must match filename)
  • session_id — session identifier (must match filename)

All centroid arrays must have identical length. Coordinates may be floats or integers.

Optional fields

Additional fields may be present in the dictionary and are safely ignored by the pipeline. This allows upstream tools to attach metadata without breaking compatibility.

  • ROI spatial footprints
  • Fluorescence traces
  • Timestamps or frame indices
  • Shape descriptors (area, convexity, entropy)

Think of these as permitidos (permitted), not required.

Current limitations

This is an early release. At present:

  • No bundled example dataset is provided
  • Only centroid-based matching is enforced at the interface level
  • All sessions for a given animal must share a consistent pixel coordinate system
