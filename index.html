🌌 Constellation-Inspired Neuron Matching

Stars2Cells is a cross-session neuron matching framework inspired by astronomical star-matching (e.g., constellation/asterism matching). It focuses on robust registration under drift, nonrigid changes, and partial overlap by combining geometric hashing with local transform hypothesis testing.

The goal: reliably identify the same neuron across sessions using spatial relationships—rather than relying on a single global transform or fragile heuristics.

🧩

Quad-Based Hashing

Sample quads across scales to create local, discriminative geometric signatures.

🧭

Local Transform Hypotheses

Test candidate local alignments rather than committing to a single global affine model.

🧠

Neuron-Aware Filtering

Shape descriptors (area, convexity, entropy) help reject implausible matches early.

📈

Scale & Partial Overlap

Designed to be robust when fields of view shift or only partially overlap across days.
